REST API для системы записи к врачу в клинику. Позволяет управлять специальностями, врачами и записями на приём. Поддерживает роли: пациент, врач, администратор.

## Стек технологий

- PHP 8.3
- Laravel 13
- SQLite (встроенная база данных)
- Laravel Sanctum (токен-аутентификация)
- Swagger / OpenAPI 3.0 (документация)
- Composer

## Установка и запуск

### 1. Клонировать репозиторий

```
git clone https://github.com/1KuRoK1/Clinic-Appointment.git
cd Clinic-Appointment
```
### 2. Установить зависимости
```
composer install
```
### 3. Создать файл .env
```
copy .env.example .env
```

### 4. Сгенерировать ключ приложения
```
php artisan key:generate
```
### 5. Настроить базу данных (SQLite)
Создать пустой файл базы данных:

```
type nul > database\database.sqlite
```

В файле .env указать:

```
DB_CONNECTION=sqlite
```

### 6. Прогнать миграции
```
php artisan migrate
```
### 7. Запустить сервер
```
php artisan serve
``` 
* API будет доступен по адресу: http://127.0.0.1:8000
* Документация API (Swagger UI)
* После запуска сервера открой в браузере:

http://127.0.0.1:8000/api/documentation
В открывшемся интерфейсе представлена интерактивная документация всех эндпоинтов с примерами запросов и ответов. 
Для тестирования защищённых методов нажми кнопку "Authorize" и введи полученный токен Sanctum.

Роли пользователей:

* Гость - регистрация, логин, просмотр списка врачей
* Пациент - всё, что доступно гостю, плюс запись на приём, просмотр своих записей, отмена
* Врач - просмотр своего расписания и записей к себе
* Администратор - управление врачами, специальностями, всеми записями



### Структура базы данных
* users — пользователи (пациенты, врачи, администраторы)
* specialties — медицинские специальности
* doctors — врачи (привязаны к пользователю и специальности)
* appointments — записи на приём (пациент, врач, время)
* personal_access_tokens — токены Sanctum
